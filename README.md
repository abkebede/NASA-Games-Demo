# NASA GAMES Mini Mission Demo

This folder is ready for static hosting with GitHub Pages.

The demonstration follows one complete scientific chain:

NASA data -> space-weather analysis -> radiation/survivability calculation -> mission decision.

Open `index.html` locally, or publish this folder from a GitHub repository with GitHub Pages.

The bundled NASA/SPDF OMNI2 interval is measured upstream near Earth. Operational thresholds and survivability coefficients in the mini-demo are educational assumptions and are not NASA flight rules.

A companion notebook is included at `notebooks/01_space_weather_survivability.ipynb` to show the data, equations, calculations, and plots behind the browser demonstration.


## Artemis Mission Physics Track

The demo now includes a 10-day Artemis mission-learning track. Each mission phase identifies:
- the physics principle,
- governing equation,
- computational activity,
- student interpretation question,
- linked NASA GAMES module.

A companion notebook is included at `notebooks/02_artemis_mission_physics.ipynb`.
